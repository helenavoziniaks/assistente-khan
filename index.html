📗 Assistente Khan

Um painel sobreposto à Khan Academy com cálculo passo a passo para operações, porcentagens e equações. Sem API paga.

Arraste o botão verde para sua barra de favoritos:

Assistente Khan
  1. Mostre a barra de favoritos com Ctrl + Shift + B.
  2. Arraste o botão acima para a barra de favoritos (não basta clicar nele).
  3. Acesse uma questão na Khan Academy, selecione o enunciado ou copie-o, e clique no favorito.
  4. Use Resolver com etapas, ou copie o problema para analisar no ChatGPT.

Se o navegador ou a Khan Academy bloquear o carregamento externo, use o favorito alternativo do arquivo bookmarklet-autocontido.txt, disponível neste repositório.

Este assistente não extrai gabaritos ocultos, não altera respostas e não envia tarefas automaticamente.
